PRINCESS SPA — QR-КОД ДЛЯ ОТКРЫТИЯ САЙТА

QR-код на странице «Контакты» открывает адрес PUBLIC_BASE_URL, если он задан. После публикации сайта на домене с HTTPS QR будет работать через Wi-Fi, мобильный интернет и другие сети.

ВАЖНО:
- Сам QR-код не публикует сайт в интернете.
- Если сайт запущен только на компьютере через start.bat, адрес 192.168.x.x доступен только в той же локальной сети.
- Для доступа откуда угодно разместите приложение на сервере с публичным IP, подключите домен, HTTPS и укажите PUBLIC_BASE_URL=https://ваш-домен.
- Для готового варианта через Docker и Caddy см. README_DEPLOY.txt.

Локальный режим для теста остаётся прежним: запустите start.bat и откройте QR на странице «Контакты» в одной Wi-Fi сети.
