PRINCESS SPA — ОПЛАТА ЧЕРЕЗ KASPI QR И НА МЕСТЕ

В форме записи доступны два способа оплаты:
1. Kaspi QR — онлайн-предоплата 20% либо полная оплата 100%.
2. Оплата в салоне — наличными или картой при посещении, без предоплаты.

Клиент выбирает сумму, получает страницу оплаты с QR-кодом, точной суммой и номером записи. QR ведёт на ссылку удалённой оплаты, которую салон получает в Kaspi Pay.

ПОДКЛЮЧЕНИЕ KASPI QR
1. В Kaspi Pay откройте «Удалённо» → «Ссылка для оплаты». Для руководителя/управляющего/бухгалтера: Kaspi Pay → «Удалённая оплата» → «Ссылка для оплаты».
2. Скопируйте ссылку своей точки продаж.
3. В файле .env укажите её в KASPI_PAYMENT_URL=https://...
4. Перезапустите приложение.

Официальные инструкции Kaspi: как получить ссылку — https://guide.kaspi.kz/partner/ru/pos/payments/remote/q2019 ; как клиент оплачивает по ссылке — https://guide.kaspi.kz/partner/ru/pos/payments/remote/q2098

Важно: общая ссылка удалённой оплаты Kaspi открывает приложение Kaspi, а клиент сам вводит сумму. Поэтому сайт показывает точную сумму, которую нужно ввести, и номер записи для комментария. Это не API-эквайринг: автоматическая сверка оплаты по webhook не подключена. Kaspi Pay присылает уведомление кассиру; после проверки администратор нажимает «Подтвердить оплату» в панели. Не отмечайте оплату полученной, пока не проверили её в Kaspi Pay.

Без KASPI_PAYMENT_URL вариант Kaspi QR будет отключён, чтобы не создавать ложные обещания оплаты. Оплата на месте продолжит работать.

QR-КОД САЙТА
Для QR, который открывает сам сайт из мобильного интернета и любой другой сети, нужен опубликованный HTTPS-адрес. Укажите его в PUBLIC_BASE_URL. Локальный адрес вида 192.168.x.x работает только в локальной сети и не может открываться извне.
