PRINCESS SPA — ПУБЛИКАЦИЯ В ИНТЕРНЕТЕ (HTTPS + QR)

Этот проект можно развернуть на VPS/сервере с публичным IP через Docker Compose и Caddy. Caddy автоматически запросит TLS-сертификат для домена.

ПОДГОТОВКА
1. Купите/используйте домен и настройте DNS A-запись домена на публичный IP сервера.
2. На сервере должны быть доступны входящие порты 80 и 443.
3. Установите Docker Engine и Docker Compose plugin.
4. Скопируйте папку проекта на сервер.
5. Создайте файл .env на основе .env.example и замените SITE_DOMAIN на свой домен.
6. В KASPI_PAYMENT_URL вставьте удалённую ссылку оплаты из Kaspi Pay. Если пока не подключили Kaspi Pay, оставьте поле пустым — онлайн-оплата будет отключена, оплата в салоне останется доступна.
7. Запустите: docker compose up -d --build

После запуска откройте https://ваш-домен. QR на странице «Контакты» будет вести на PUBLIC_BASE_URL и работать из любой сети при условии, что домен и сервер доступны.

ДАННЫЕ И ОБНОВЛЕНИЯ
- SQLite хранится в каталоге ./data на сервере (Docker volume), поэтому контейнер можно пересоздавать без удаления базы.
- Перед обновлением проекта сделайте резервную копию ./data.
- Не публикуйте файл .env и не отправляйте его в общие чаты: в нём находится приватная ссылка Kaspi Pay и настройки сервера.
- Для надёжной эксплуатации регулярно копируйте ./data/spa.db в защищённое место.

ЛОКАЛЬНЫЙ ЗАПУСК
Windows: start.bat — только локальный тест/локальная сеть. Для интернета используйте домен и сервер по этой инструкции.
